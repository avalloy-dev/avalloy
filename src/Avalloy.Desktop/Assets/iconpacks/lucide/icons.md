# Lucide — curated role aliases

Semantic role names baked over the slug set (same `Icon.<Role>` resource space; the
picker still enumerates slugs only). Avalloy's OWN control layer references the
first five — AlloySelect's caret/check (`Chevron`, `Check`) and AlloyTextBox's affixes
(`Close`, `Warning`, `Success`) — so the baseline pack must define them for those
controls to render outside a brand pack. The rest are shell staples a starter app
reaches for. Format per Avalloy.IconTool: a table row of bold role + backticked svg path.
